For SSO profiles run aws sso login --profile <name> first. Env vars, ~/.aws/credentials, source_profile chaining, and the SSO token cache are all supported.
Bedrock connects through its OpenAI-compatible endpoint (https://bedrock-runtime.{region}.amazonaws.com/openai/v1). Two auth modes: Bedrock API key (sent as the bearer token) or AWS profile / SSO (every request signed with AWS SigV4 from your AWS credential chain — env vars, ~/.aws/credentials, ~/.aws/config with source_profile chaining, and the SSO token cache). The model field accepts a model id, an inference-profile id, or a full ARN (foundation-model, inference-profile, application-inference-profile, or provisioned-model).
Keys are written to VS Code SecretStorage and passed to the sidecar via environment variables. They never appear in settings JSON, events, logs, or the contract block.

Environment (per-project provider bindings)

Environments come from .awino/providers.yaml. Switching changes which provider + model + key the harness uses — project A can never see project B's key. Keys stay in secret storage; only key references live in the file.

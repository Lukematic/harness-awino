Bedrock connects through its OpenAI-compatible endpoint (https://bedrock-runtime.{region}.amazonaws.com/openai/v1) with the Bedrock API key as the bearer token. The model field accepts a model id, an inference-profile id, or a full ARN (foundation-model, inference-profile, application-inference-profile, or provisioned-model). AWS SSO / shared-config profiles aren't supported in the extension yet.
Keys are written to VS Code SecretStorage and passed to the sidecar via environment variables. They never appear in settings JSON, events, logs, or the contract block.

Environment (per-project provider bindings)

Environments come from .awino/providers.yaml. Switching changes which provider + model + key the harness uses — project A can never see project B's key. Keys stay in secret storage; only key references live in the file.
